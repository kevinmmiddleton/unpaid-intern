# Unpaid Intern: the no-install kit

For companies that don't allow add-ons, plugins, skills, or scripts. If your company approved an AI assistant at all, you can still have a second brain. It just takes one more step at the end of each session: saving the files it hands you.

## Pick the one that matches what you're allowed

**1. You can make a Claude Project** (or your approved assistant lets you save instructions and upload files)

1. Unzip `Second Brain` somewhere your company lets you keep work files: your work OneDrive or Google Drive folder, or Documents.
2. Make a new Project. Paste everything in `INSTRUCTIONS.md` into the Project's instructions.
3. Upload these files from your `Second Brain` folder to the Project (skip the README and template files; the assistant doesn't need them):
   - `START-HERE.md`
   - `Memory/project-status.md`, `Memory/followups.md`, `Memory/decisions.md`, `Memory/meetings.md`, `Memory/lessons.md`
   - `4-Reference/people.md`, `4-Reference/glossary.md`
   - `Setup/preferences.md`
   - Later, each active project's `current.md`. If the Project won't take two files with the same name, rename them first, like `launch-v2-current.md`.
4. Start a chat in the Project and say "set me up."
5. At the end of each session, say "wrap up." It hands you each changed file with the folder it belongs in. Save each one over the old copy in your folder. In the Project, delete the old copy and upload the new one, so there's only ever one version.

**2. You can only chat**

1. Unzip `Second Brain` the same way, so you have a home for your notes.
2. Start a chat and paste everything in `QUICK-START-PROMPT.md` as your first message.
3. Paste in whatever you're working on: a meeting invite, a transcript, an email thread, a document.
4. At the end, say "wrap up" and save what it hands you into your folder.

**3. You can't use AI for work data yet**

Use the folder on its own. It still works as a place to put things: an inbox, one folder per project, and a list of follow-ups. Then ask IT which AI tool, if any, is approved for work, and come back to option 1 or 2 when there is one.

## What's in the folder

| Folder | What lives there |
|---|---|
| 1-Inbox | Anything you drop in: transcripts, PDFs, screenshots, exports |
| 2-Projects | One folder per project: where it stands, what was decided, the sources |
| 3-Areas | The ongoing parts of your job with no end date |
| 4-Reference | The glossary, the people you work with, clean notes from sources |
| 5-Archive | Finished projects and filed drops. Nothing is ever deleted |
| Memory | Project status, follow-ups, decisions, meetings, and a daily log |
| Setup | Your preferences and what the assistant is allowed to do |

## Ground rules

- Only use the AI account your company approved for work.
- Keep passwords, customer records, and anything your company says is off-limits out of the folder and the chat.
- The assistant drafts. You send.
