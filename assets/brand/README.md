# Unpaid Intern brand files

A pink brain in chunky glasses, with no eyes. It's the second brain, it did the reading, and it isn't pretending to be a person.

## Files

| File | Use |
|---|---|
| `lockup-horizontal.svg` | The default logo: mark left, wordmark right. Transparent background |
| `lockup-horizontal-on-paper.svg` | The same on the Paper background, for READMEs and slides |
| `lockup-stacked.svg` | Mark above the wordmark, for square spaces |
| `mark.svg` | The brain alone |
| `mark-ink.svg`, `mark-paper.svg` | One-color line versions for light and dark backgrounds |
| `wordmark-stacked.svg`, `wordmark-line.svg` | The name alone, stacked or on one line |
| `app-icon.svg` | 512 x 512 rounded square on Highlighter yellow |
| `favicon.svg` | Simplified mark (fewer folds, heavier lines) for 16 to 64 pixels |
| `social-card.svg` | 1200 x 630 card: the logo and "A second brain for work." (same as the link preview banner) |
| `banners/` | The official banner in every size, each as SVG, PNG, and @2x PNG: `link-preview-1200x630` (LinkedIn link posts, Open Graph), `github-social-1280x640` (GitHub repo social preview), `wide-1600x900` (blog cover, X; everything sits inside a centered square, so square crops are safe), `square-1080x1080` (LinkedIn and Instagram feed), `portrait-1080x1350` (tall feed posts) |
| `png/` | PNG exports: app icon at 1024, 512, and 180; favicon at 64, 32, and 16; lockups; mark; social card |

Every file is filled paths only: no fonts, no strokes, no CSS. They open the same way everywhere.

## Rules

- **Clear space:** keep at least the width of one lens empty around the logo.
- **Minimum size:** the horizontal lockup at 24 pixels tall; below that, use the mark or the favicon.
- **Never** add eyes, a mouth, a tongue, gradients, shadows, or a lab coat. Never recolor the brain to a realistic brain color.
- **Type:** the wordmark started from Poppins Bold (SIL Open Font License), then got outlined, slightly emboldened, and rounded at the corners. For body text next to the logo, Poppins or any clean geometric sans works.
