# Memory

The lists your assistant keeps up to date, so nothing starts from scratch:

- **project-status.md**: every project, its status, and its next step
- **followups.md**: what you owe and what you're waiting on, with dates
- **decisions.md**: decisions across all projects, with the why
- **meetings.md**: a short log of meetings and where their notes live
- **lessons.md**: corrections, so the same mistake doesn't happen twice
- **scratch-today.md**: today's loose threads
- **day-log**: one short page per working day

You can open and edit any of these yourself. Keep the format at the top of each file; the tools read it.
