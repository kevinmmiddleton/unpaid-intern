# Projects

Work with a finish line. One folder per project, named with a short slug, for example `launch-v2`.

Each project folder has four pages, copied from `_template`:

- **current.md**: where it stands right now, rewritten as things change
- **decisions.md**: what was decided and why, newest first
- **sources.md**: the meetings, docs, and threads behind it
- **context-map.md**: the people, systems, and other projects it touches

Say "start a project called ..." or /new-project and the assistant sets it up. When a project is done, it moves to 5-Archive/projects. Nothing is deleted.
