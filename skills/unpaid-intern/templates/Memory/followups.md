# Follow-ups

One line per commitment. Order does not matter; the tools sort by date.

Format: `- [ ] YYYY-MM-DD | @owner | deliverable #project-slug | source | accepted: true|false`

- `@me` is your own commitment. `@waiting:Name` is someone else's.
- `accepted`: true for your own commitments (`@me`). For `@waiting` items, true only when the other person agreed, with the quote in the source; otherwise false.
- Put `~` before a guessed date. Add `since:YYYY-MM-DD` to the source to track how long you have been waiting.
- Mark done with `[x]`. Never delete a line to make it go away.
